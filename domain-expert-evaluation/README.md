# IPMs of the domain experts (paper, Section 7.3)

Five people described a process from their own work in a three- to six-minute narrative. An IPM was
generated from each narrative with the prototype, without manual correction, and the participant then
reviewed it in an individual session.

| File | Participant | Process described |
|------|-------------|-------------------|
| `generated-ipms/domain_expert_1_sales.drawio` | Sales adviser in a sports shop | In-store sale, from first contact to payment |
| `generated-ipms/domain_expert_2_baggage.drawio` | Baggage handler, airport ground handling | Loading and unloading the baggage of a flight |
| `generated-ipms/domain_expert_3_check_in.drawio` | Check-in agent, airport ground handling | Passenger check-in and boarding |
| `generated-ipms/domain_expert_4_study_programme.drawio` | Student who models regularly (contrast case) | His study programme |
| `generated-ipms/domain_expert_5_access_programme.drawio` | University programme adviser | University access programme |

Each file has three pages: the IPM grid (Makigami), a process view and a BPMN view. Hovering a cell shows
the line of the narrative it comes from. The files are the IPMs as generated and shown to the participants,
before their corrections.

Published with the consent of the participants. Names of employers, programmes and places were replaced by
neutral placeholders in square brackets (for example `[entreprise d'assistance au sol]`). The narratives
themselves and the session notes are not published.
