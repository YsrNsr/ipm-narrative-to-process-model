# From Narrative to Process Model: the Intermediate Process Model (IPM)

Companion repository of the paper

> Y. Nasser, J. Ralyté. *From Narrative to Process Model: Enabling Non-Expert Participation Through an
> Intermediate Representation.* PoEM 2026 Forum, Companion Proceedings of the 19th IFIP WG 8.1 Working
> Conference on the Practice of Enterprise Modeling (PoEM-C 2026), CEUR Workshop Proceedings.

The paper proposes the **Intermediate Process Model (IPM)**, a grid that sits between a process narrative
told by a domain expert and the formal model drawn by a modelling expert. An LLM structures the narrative
into a JSON object, a program checks it and renders it into an editable Draw.io grid, the domain expert
reviews and corrects the grid, and the modelling expert formalizes it.

This repository contains the prompts, the narratives, the generated models, the evaluation reports and the
source code of the prototype. Most material is in French, the language of the study. English translations
are provided for the prompts and the motivating narrative.

## What is not included

To protect the participants, the following are not published: the audio recordings and transcripts of
the sessions, the real interview transcript and the workshop transcript used in the technical verification
(cases `07_real_interview` and `08_real_workshop`), and every file derived from their content. The
evaluation reports keep only the scores of case 07. Scripts that need these files (for example
`agent/eval/grounding-eval.mjs`) cannot be rerun from this repository.

## Running the prototype

Requirements: Node.js 20 or later, and either an API key for a cloud model (Anthropic or OpenAI) or a
local model served by Ollama.

```bash
cd agent
npm ci
cp .env.example .env      # then set PROVIDER and the matching key or Ollama settings
npm test                  # offline tests, no API key needed
npm start                 # http://localhost:3000
```

More details (in French) in [`agent/README.fr.md`](agent/README.fr.md) and
[`agent/QUICKSTART.md`](agent/QUICKSTART.md). Generated outputs depend on the model and its version, so a
new run will not reproduce the reported figures exactly.
